# GitWayfinder feedback

Report errors, flag outdated instructions, and suggest improvements to [GitWayfinder](https://gitwayfinder.shuvit.dev/).

- [Browse existing issues](https://github.com/doeza/gitwayfinder-feedback/issues)
- [Report an error](https://github.com/doeza/gitwayfinder-feedback/issues/new?template=correction.md)
- [Suggest an improvement](https://github.com/doeza/gitwayfinder-feedback/issues/new?template=suggestion.md)

Issues are public. For feedback you want to share privately, use the email link on the [About page](https://gitwayfinder.shuvit.dev/about#contribute).
